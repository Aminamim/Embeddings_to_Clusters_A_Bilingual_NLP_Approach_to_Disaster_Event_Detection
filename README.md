Natural hazards are increasingly frequent and severe, affecting millions globally and placing immense pressure on crisis response systems. For countries where resources are limited and language barriers exist, the need for effective, real-time disaster detection from local data sources is crucial for minimizing harm and maximizing response efficiency. In Bengali-speaking regions, one of the world’s most vulnerable areas to climate-induced disasters, a lack of automated tools for disaster event detection presents significant challenges. This research focuses on building a robust framework for disaster event detection by leveraging advanced Natural Language Processing (NLP) techniques such as BERT embedding and FAISS clustering.
